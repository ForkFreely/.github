# ForkFreely

Welcome to ForkFreely! We build open-source alternatives to the everyday SaaS tools that teams usually rent, and we release them for anyone to use, study, and improve.

Our mission is to give people software they truly own. Every project is built to be self-hosted, easy to understand, and simple to fork, so you can adapt it to your needs, rebrand it, or take it in a direction of your own. We keep each tool small and focused, with clean code and minimal dependencies, so that changing it is as easy as running it.

Contributions are always welcome, whether that's reporting an issue, suggesting an improvement, or opening a pull request. Each repository includes its own license and contribution guide.
